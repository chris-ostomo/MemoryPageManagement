# MemoryPageManagement
C++ program that simulates a multi-level page table system with trace-based logging.

### HOW TO USE:
1. Use a Linux distribution (e.g., Ubuntu) to compile files specified by the Makefile.
2. Type the command ```make``` in a Linux terminal to compile the required files.
3. Test with commands ```./pagetrace trace.tr "4 8 8"```, ```./pagetrace trace.tr "7 15"```, ```./pagetrace trace.tr "6 6 6"```, or any numeric levels you would like.
4. Unsatisfied? Type ```make clean``` and modify my code!
5. Profit.
