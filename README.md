# MemoryPageManagement
C++ program that simulates a multi-level page table system with trace-based logging.

### HOW TO USE:
1. Use a Linux distribution (e.g., Ubuntu) to compile files specified by the Makefile.
2. CD into the download directory in a Linux terminal.
3. Type the command ```make``` to compile the required files.
4. Test with commands ```./pagetrace trace.tr "4 8 8"```, ```./pagetrace trace.tr "7 15"```, ```./pagetrace trace.tr "6 6 6"```, or any numeric levels you would like.
5. Unsatisfied? Type ```make clean``` and modify my code!
6. Profit.
